# PWA + logo — Colombia Día a Día

Sube al directorio raíz del repositorio:

- `manifest.webmanifest`
- `sw.js`
- `logo-colombia-dia-a-dia.png`
- carpeta `icons/`

Luego copia las etiquetas de `INSTALL-SNIPPET.html` dentro de `index.html`:
- el primer bloque va dentro de `<head>`
- el script va justo antes de `</body>`

Después de que Netlify despliegue el commit, la web quedará preparada para instalarse como PWA y usar el nuevo logo/ícono.
